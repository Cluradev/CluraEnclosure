# CAD Models

Full assembly models for each enclosure are provided as STEP files, one per size. Fusion 360 source files are currently being refined and will be released in the near future.

These are reference models of the complete enclosure. The files you actually fabricate from live elsewhere:

- **`3D Printable Files/`** in the repository root: the `.3mf` files you print
- **`Production/`**: STEP models of every cut extrusion, DXF for the acrylic panels and metal plates, and the PCB gerbers

### Compatibility
- **PE1**: Prusa i3 MK3 / MK4
- **BE1**: Bambu Lab A1, Creality HI, Ender 3 and similar Ender-style printers
- **ME1**: Prusa Mini, Bambu Lab A1 Mini
