# CAD Models

Full assembly models for each enclosure are provided as STEP files. Fusion 360 source files are currently being refined and will be released in the near future.

The `production` folder contains:
- **STL files** for 3D printing.
- **STEP files** for aluminum extrusions.
- **DXF files** for panel fabrication.

### Compatibility
- **PE1**: Prusa i3 MK3 / MK4
- **BE1**: Bambu Lab A1, Ender 3, and similar Ender-style printers
- **ME1**: Prusa Mini, Bambu Lab A1 Mini
